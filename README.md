# YOYI! Website — GitHub Pages

## Upload
Upload seluruh isi folder ini ke repository GitHub.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → main → / (root) → Save.

## Struktur
- index.html — Homepage
- yoyi-box.html — YOYI! Box
- yoyi-station.html — YOYI! Station
- location.html — YOYI! Location
- locations.csv — database lokasi
- css/style.css — desain
- js/script.js — fungsi umum
- js/location.js — pencarian lokasi

## Catatan
Website sudah tidak menggunakan Google Apps Script. Untuk menambah lokasi, cukup edit `locations.csv` lalu commit/push ke GitHub.
